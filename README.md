# Игротека (Igroteka) 🎮

**v1.1.0 Stable — Clean Data Edition** · Windows 11 x64 · Tauri 2 / Rust / SQLite

Настольное приложение для ведения личной библиотеки игр: список игр, оценки, избранное и корзина. Интерфейс выполнен в тёмной теме *Cinema Mono* с анимированными частицами.

**[Скачать Portable-версию](https://github.com/TraurigerEngel/Igroteka/releases)** · [Конфиденциальность](GITHUB_PRIVACY_RU.md) · [История изменений](CHANGELOG.md)

## Возможности

- Удобная библиотека игр с поиском и сортировкой.
- Оценки, избранное, управление записями и корзиной.
- Локальная SQLite-база с сохранением и восстановлением данных.
- Тёмный интерфейс, собственная строка заголовка, плавная заставка.
- Эффект *Living Particles* с ограничением нагрузки.
- Отдельное портативное приложение для Windows 11 x64.

## Установка

1. Откройте раздел [Releases](https://github.com/TraurigerEngel/Igroteka/releases).
2. После публикации скачайте **`Igroteka_v1.1.0_Clean_Portable.zip`**.
3. Распакуйте архив в постоянную папку и запустите **`Igroteka.exe`**.
4. Не удаляйте каталог **`data`**, если вы уже добавили игры: там находится ваша рабочая библиотека.

**Важное примечание:** официальная публикация Clean Portable ожидает подтверждения запуска на Windows, включая проверку поведения частиц у краёв окна. Исходный пакет содержит неизменённый EXE, но две базы данных обезличены.

## Безопасность и демонстрационные данные

В оригинальном архиве было 640 пользовательских игр. Для GitHub подготовлена **совершенно новая пустая база**, без исходных названий, оценок, избранного и дат изменения:

- `seed-data/igroteka.sqlite3` — чистая стартовая база с **0 играми и 0 записями корзины**.
- Рабочая `data/igroteka.sqlite3` **не включена в Git** и защищена `.gitignore`.
- Исходные личные записи и файлы резервных копий не публикуются.
- После клонирования создайте локальную базу командой `INIT-DEMO-DATA.cmd`: существующая база **никогда не перезаписывается**.

Политика обработки данных: [GITHUB_PRIVACY_RU.md](GITHUB_PRIVACY_RU.md).

## Разработка и сборка

Понадобятся **Node.js 22.13+**, npm, **Rust (MSVC)** и компоненты сборки Tauri 2 для Windows.

Откройте PowerShell в корне клонированного проекта:

```powershell
.\INIT-DEMO-DATA.cmd
npm ci
npm run verify
npm run build:dev
```

Для создания релизной сборки на Windows после проверок:

```powershell
.\MAKE-FINAL-RELEASE.cmd
```

Полный порядок приёмки описан в [RELEASE-CHECKLIST.md](RELEASE-CHECKLIST.md). Проверки фиксируют неизменность логики и исходников Rust, проверяют чистую SQLite-базу и поведение эффекта частиц. В GitHub-варианте для исходной сборки используется системный шрифт Inter, если он установлен, иначе шрифт по умолчанию.
