# Igroteka v1.1.0 Stable — Clean Data Edition 🎮

Портативная библиотека игр для Windows 11 x64. Репозиторий подготовлен на основе исходных материалов `v1.1 Stable`.

## Возможности

- Поиск, сортировка, оценки и избранное.
- Корзина и восстановление записей.
- Локальное хранение в SQLite.
- Тёмный интерфейс Cinema Mono, 42px строка заголовка, плавная заставка.
- Улучшение отрисовки частиц при переходе через границу canvas.

## Конфиденциальность

Публикуемый Clean Portable не содержит исходные 640 игр: обе внешние базы SQLite пустые и идентичные (0 игр, 0 записей корзины). Программа `Igroteka.exe` не изменялась.

## Установка

1. Скачать `Igroteka_v1.1.0_Clean_Portable.zip` из Assets, когда он будет опубликован.
2. Распаковать архив и запустить `Igroteka.exe`.
3. Папка `data` содержит изменяемую библиотеку и должна сохраняться при переносе приложения.

**Примечание о проверке:** корректировка следов частиц ещё требует визуального подтверждения на Windows. Не считать Clean Portable окончательно проверенным без пользовательского теста.
